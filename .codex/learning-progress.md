## Следующий урок

Закрепить проверку значения поля:

```ts
const titleInput = page.getByLabel('Title');
await titleInput.fill('Купить хлеб');
await expect(titleInput).toHaveValue('Купить хлеб');
```

В `expect` передаём локатор поля, в `toHaveValue` — ожидаемый текст. Незавершённое упражнение: написать через `titleInput` проверку значения `'Позвонить врачу'`. Начать с него без перехода к новой теме.
