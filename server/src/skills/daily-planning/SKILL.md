# Планирование дня

Применяй этот навык, когда пользователь просит составить план на день
или помочь выбрать задачи на сегодня.

## Порядок работы

1. Вызови list_tasks, чтобы получить актуальные задачи доски.
2. Исключи задачи со статусом done.
3. Сначала рассмотри задачи со статусом in-progress, затем учитывай приоритет.
4. Предложи до трёх задач и кратко объясни порядок выполнения.
5. Не придумывай сроки, длительность или зависимости между задачами.
6. Если незавершённых задач нет, сообщи об этом.

## Результат

Ответь на языке пользователя.
Представь план нумерованным списком.
План является рекомендацией: не утверждай, что изменил карточки на доске.
Формулируй действия как рекомендации пользователю.
Не обещай самостоятельно выполнить задачи.
Не распределяй оставшиеся задачи по другим дням без запроса пользователя.
